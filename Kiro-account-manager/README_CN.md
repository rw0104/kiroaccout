# kiroaccout 应用源码

本目录为 Electron 应用源码。使用说明见[项目首页](../README.md)，安装包见 [Releases](https://github.com/rw0104/kiroaccout/releases)。

当前源码目标为 **1.8.11 · Windows x64**，发布状态与附件以 Releases 为准。账户绑定与轮换保护已做合成数据回归，双真实账户登录及刷新尚未完成验收。单个 Social 会话的 Runtime 检查已实测成功；完整验收范围见发布说明。

在“添加账户 → 在线登录 → 打开 Kiro 网页登录”进行门户登录。在“账户管理”或“设置 → 数据管理 → 导出”选择全部/选中、完整备份 JSON 或精简凭证 JSON。默认不含凭证，不能恢复登录；需要迁移登录信息时明确勾选包含凭证，并妥善保存明文文件。

安全更新：代理 HTTPS 校验证书，远程图片仅允许公网地址，推理 Key 不再具有 HTTP 管理权限。账户数据首次启动时自动迁移到系统密钥保护的加密库；请先解锁系统钥匙串。跨机器迁移使用显式包含凭证的导出，旧版不能直接读取新库。

“Kiro 设置”支持为默认 IDE 或选定受管实例设置 Memory 和 Workflows，保存时保留 JSONC 注释及其他配置。账号搜索支持原始导入名称；模型卡片在目录倍率与已核对规则一致时显示上下文阶梯倍率。

“Kiro 隔离多开”共用一份官方 Kiro.exe，每个命名实例有独立的配置、home、扩展、shared data 和临时目录。选择程序、实例名称和管理器内已有账户后创建并启动；启动时只向专用缓存写入该账户凭证，无需额外 Windows 用户、重复安装或系统密码。访问凭证过期可由实例续期，刷新凭证或 IdC 客户端登记失效需重新授权。

创建配置仅记录账户选择；启动准备失败且确认未启动客户端时，原账户仍可在管理器使用，配置可直接移除。启动交接后，实例独占该账户的刷新，管理器拒绝重复绑定、刷新及切号。复制缓存不会改写原账户的登录方式、提供商或 profile；核验后的凭据变化只同步 Token 和到期时间。启动前只读比较默认 IDE 的凭证，发现共用时拒绝启动，不复制或改写其缓存。先停止并同步最新凭证，再移除绑定；IDE 中改登其他账户不能盲目覆盖原管理账户。不要在旧管理器或其他客户端同时刷新同一账户。

若缓存丢失、过期或改登导致无法同步，可在停止实例后选择“恢复解绑”并确认。全部实例文件保留，原账户需重新授权，未核验凭证不会回写。

页面提供运行状态、正常停止和重启。未保存编辑可能阻止关闭，不会自动强杀；移除配置保留资料。旧 RC 的 Windows 用户配置已停用，需移除后重建。系统网络、代理、证书、Windows 身份和 DPAPI 仍共享，不是安全沙箱。
