# kiroaccout application

Electron application source. See the [project README](../README.md), [development guide](../docs/DEVELOPMENT.md) and [Windows downloads](https://github.com/rw0104/kiroaccout/releases).

Use Account Management for JSON imports, Add Account → OIDC Token → Batch for pasted credentials, and About → Check Updates for version checks. Back up existing data before upgrading; the ZIP package does not provide data isolation.
