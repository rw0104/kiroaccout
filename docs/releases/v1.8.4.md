# v1.8.4 · Windows x64

本版修复多开实例已移除后，带有“实例凭证未核验”恢复标记的账户仍无法删除的问题。

## 修复内容

- 用户明确删除没有实例绑定的恢复账户时，无需先重新授权。仍由多开实例管理的账户继续禁止删除，应先停止实例并解除绑定。
- 删除只允许处理本次明确选中的账户。普通保存和旧窗口快照继续保护恢复记录，防止意外漏记导致账户被删除；其他账户资料不受影响。
- 账户删除成功落盘后才从界面、反代账户池和暂存成员中移除；保存失败时保留账户并提示失败。
- 恢复记录与当前列表不一致时，提示重新加载账户后重试，不再要求先完成重新授权才能删除。

## 验证与升级说明

- 使用合成账户的离线单元回归 **356 项全部通过**，覆盖未绑定恢复账户的明确删除、绑定保护、普通保存、失败回滚、反代池清理及删除后的本地凭据检查。
- Node 与渲染层类型检查、生产构建通过。
- 本轮未执行真实账户删除或安装验收。

**不需要重新安装到新目录，也不需要清空 APPDATA。** 常规安装到其他目录或使用 ZIP 仍默认共享同一份账户管理器数据；升级本版后可直接删除未绑定的恢复账户。

本版删除账户不会删除保留的实例文件，不会自动解除仍存在的实例绑定，也不会恢复已经失效的 Token。需要继续使用失效凭证的账户，仍须重新授权。
