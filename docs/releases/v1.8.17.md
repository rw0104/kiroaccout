# Kiro Account Manager v1.8.17

修复“工具自动批准”首次使用时提示“目标主目录不存在”、无法读取或应用配置的问题。

- 管理器尚未创建权限备份目录时，可以正常读取所选客户端的权限状态。
- 按当前系统用户解析配置路径，兼容中文或含空格的用户名。新安装的 Kiro 尚无 `.kiro` 配置目录时显示“未配置”；查看状态不会创建目录，点击“应用自动批准配置”后再创建所需目录及备份。已有权限规则继续保留。
- 权限读取失败后显示“读取失败”并提供“重试”，不再一直显示“加载中”。

路径、链接、文件访问权限及备份冲突检查继续生效。仅有 `permissions.json` 时保持只读，可导出 YAML 模板自行迁移。

升级前退出旧版管理器并备份完整账户数据目录。安装后打开“Kiro 设置 → 工具自动批准”重新检查所选客户端。

离线回归、类型检查、构建及安装包校验结果以本次 Release 为准。真实客户电脑上的 GUI 和工具确认行为仍待验收。

macOS 安装包未签名及公证；macOS / Linux 请手动升级，多开仍仅支持 Windows。
