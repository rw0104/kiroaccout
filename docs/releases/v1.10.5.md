# Kiro Account Manager v1.10.5

移除独立 Crew 工作区，简化客户端账号切换。

- 客户端选择保留 IDE / Crew / CLI。选择 Crew 直接使用已有官方客户端的账号切换、授权和停止同步功能。
- 移除独立工作区的启动、打开、停止、专用窗口与后台服务，不再由管理器启动这套工作区或触发其浏览器环境准备。
- 移除对应的 Crew 源码补丁、前端副本、启动器和打包资源；更新安装与退出流程不再等待已移除的工作区服务。
- 现有工作区的会话、工作文件、登录资料和浏览器个人资料保留，不自动清除。删除功能不会自动回收旧目录的磁盘占用。

模型列表仍以官方客户端和账号实际返回为准。本次移除功能不代表官方 Crew 的异步模型目录问题已修复，也不改变现有连接器已验证的版本范围：Windows 官方 CLI 3.1.0、Crew 0.12.0。

升级前请先在旧版停止已启动的独立 Crew 工作区，备份账户资料，再退出旧版管理器。不要同时运行新旧管理器。macOS 安装包未签名及公证；macOS/Linux 请手动升级。
