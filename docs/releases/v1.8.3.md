# v1.8.3 · Windows x64

本版修复自动更新安装前的账户保存失败与更新说明显示 HTML 标签的问题，并在关于页面增加库存监控入口。

## 修复内容

- 更新安装前保存账户时，以主进程中的最新资料保留实例绑定或等待恢复的账户，兼容旧窗口未包含这些记录的情况；其余用户编辑仍正常保存。普通账户删除的校验不变，实际磁盘保存失败仍会阻止安装。
- 更新失败提示区分账户保存被拒绝、保存超时或窗口不可用，以及安装器准备失败，并提供手动下载安装包的入口。
- HTML 格式的更新说明会安全转换为可读文本，保留标题、段落和列表，避免直接显示 `<h1>`、`<p>` 等标签；页面只展示提取后的文本，不挂载更新说明中的 HTML。
- 关于页面增加[库存监控](https://12312356.xyz/)链接。

## 验证与升级说明

- 合成账户与隔离目录下的离线回归 **346 项全部通过**，覆盖更新保存、发送方与请求编号校验、保存超时、安装重试、更新说明显示及关于页入口。
- Node 与渲染层类型检查、生产构建通过。
- 本轮未执行真实自动安装或双真实账户登录、续期验收。

**从 1.8.1 升级时，如果仍出现安装前保存失败，请从本版 Release 页面下载安装包并手动安装。** 下载新版本不会替换仍在运行的 1.8.1 更新器，因此新包无法在安装前修复旧版的保存门槛。升级前请备份账户资料并正常退出旧管理器。

本版不会自动解除旧实例绑定，也不会恢复已经失效的 Token。需要恢复解绑或重新授权的账户仍须按界面说明处理。
