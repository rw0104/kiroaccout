# Kiro Account Manager v1.10.6

把 Crew 模型目录修复接入官方客户端使用流程，无需独立工作区。

- **原生 Crew 模型修复**：在账户客户端选择器中选择 Crew，可检测状态、修复模型列表或恢复官方文件。覆盖已验证的官方 Crew 0.12.0、0.12.2，模型目录晚于会话响应到达时也会保存并通知菜单刷新，解决该路径导致的仅显示 Auto。
- **冷启动目录加载**：Crew 0.12.2 的首次目录探测会短暂继续接收模型元数据，避免完整列表到达前就关闭探测会话；初始 Auto 不会被误判为加载完成。元数据等待有上限，超时、取消和换账号会清理会话，不发起额外推理。
- **直接作用于官方安装**：修复前检查签名、源码、前端与进程状态，备份原文件后更新。客户端或后台服务仍运行时拒绝写入；失败会回滚或提供明确恢复状态，不覆盖其它更新后的文件。保留正常账号切换与短期访问同步，不创建工作区、独立 Gateway 或浏览器环境。
- **旧版界面资源**：Crew 0.12.0 同时处理压缩前端资源及官方既有的界面缓存刷新，避免程序文件已更新而菜单仍运行旧代码；登录、会话和工作文件保留。
- **客户端升级检测**：Crew 根据实际登录与模型实现检查兼容性，已验证源码协议相同的小版本可继续使用；官方更新覆盖修复后重新检测，已知修复文件残留也能处理。CLI 新增官方 3.2.1 本地登录协议支持，继续支持3.1.0。未知版本或协议明确提示验证，不以旧目录或固定模型清单伪装成功。
- **动态模型目录**：保留引擎实际返回的模型和权限信息，新增模型不需要逐个修改管理器白名单。真实账号只有 Auto、套餐/区域或上游授权限制不由本地补丁绕过。
- **任务审核说明**：工具自动批准按钮改为“应用显式允许规则”，说明它与官方 Approve for Me 的区别，并展示已有 evaluate 规则统计。不会自动更改权限策略或替用户开启模型审核。

使用方式：先正常关闭官方 Crew 及后台服务，在管理器的 Crew 选项执行“修复模型列表”，然后切换账号并重新打开官方 Crew、创建新会话。官方更新后重新检测，必要时再次修复；恢复操作也要求客户端关闭。

本次覆盖离线回归、安装/恢复及更新竞争测试、官方程序副本的合成登录协议测试；没有把这些结果扩大为所有真实账号权限或所有未来破坏性升级的保证。原生连接与文件修复目前仅支持上述已验证的 Windows 客户端，macOS/Linux 管理器保持既有功能。

升级前备份账户资料并退出旧管理器。较旧版本若仍运行独立 Crew 工作区，请先停止它；旧数据不会自动删除。macOS 安装包未签名及公证；macOS/Linux 请手动升级。
