# Kiro Account Manager v1.9.0

本版跟进 Kiro IDE 1.4.121，增加账户级模型后备偏好，并改善代理的 Spec 模式和短会话续期行为。

- **模型后备偏好**：打开账户详情，读取所选账户的官方 Kiro 模型偏好。为主模型设置一个后备模型，或清除该项设置，再点击保存。保存后会重新读取确认。模型卡片保留官方同意状态；管理器不会代为同意，代理也不会自动按该偏好重试。
- **Spec 模式**：代理发送与 Spec 模式一致的任务类型。推理请求记录实际调用次数和模型后备情况，仍使用现有的推理接口。
- **短会话续期**：提前续期暂时失败时，代理可在访问凭证仍有效的窗口内继续使用。刷新明确失败且需要重新授权，或访问凭证已到期时，代理不会沿用旧凭证；刷新结果不确定时不会在当前进程自动重发同一凭证。
- **CLI 切号**：修正 macOS 的 CLI 数据目录，并识别 Windows 和 Linux 的平台数据目录设置。IdC 切号只复用与所选凭证匹配的有效原生登记。资料缺失或不匹配时，管理器提示使用 `kiro-cli login`，不写入不完整登记。
- **设置与组织用量**：Kiro 设置提供 Memory、Workflows 和压缩前后 Hooks 的官方使用说明。组织账户详情提示共享池和用户或组限制，以 Kiro 控制台为准；本版不计算共享池的个人可用余额。

升级前备份完整账户数据目录并退出旧版管理器。ZIP 或不同安装目录不会隔离管理器数据，请勿同时运行新旧版本。macOS 安装包未签名及公证；macOS / Linux 请手动升级，多开仍仅支持 Windows。

相关功能通过离线回归和构建检查。真实账户偏好写入、Token 轮换、CLI 切号、双账户桌面多开、企业共享额度和云同步仍需独立账户验收。
