# Kiro Account Manager v1.8.18

跟进 Kiro IDE 1.4.51 / Agent 1.1.615 的重连行为，修复切换账户后仍可能出现旧组织重连入口的问题。

- 切换默认 IDE 账户，以及准备 Windows 受管实例时，同步对应账户的重连来源。
- 切换为 Google / GitHub 账户时清除旧组织的重连来源；组织资料不完整时不猜测登录入口，请重新授权补齐资料。
- 重连提示无法写入时保留已经成功交接的凭证，必要时手动重新登录。
- 保留账户绑定、实例目录隔离和凭证更新保护，避免覆盖已观察到的其他客户端新状态。

相关离线回归、类型检查和生产构建已通过。真实账户授权、Token 轮换及桌面一键重连尚未完成端到端验收；本次兼容核验不代表所有订阅或模型的在线行为均已验证。

升级前备份完整账户数据目录并退出旧版管理器。ZIP 或不同安装目录不会隔离管理器数据，不要同时运行新旧版本。

macOS 安装包未签名及公证；macOS / Linux 请手动升级，多开仍仅支持 Windows。各平台发布状态和附件以本次 Release 为准。
