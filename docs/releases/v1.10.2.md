# Kiro Account Manager v1.10.2

修复凭证导入的空白分隔兼容性，并让可确认尚未建立连接的刷新失败支持恢复后再次操作。

- **卡密分隔符**：同一行可以混用 Tab 与连续空格。Tab 两侧的空格不会产生额外字段，相邻 Tab 仍保留空字段；同时兼容不换行空格与全角空格作为卡密分隔符。
- **方括号账号标签**：首字段为 `[标签]` 的完整有效卡密现在可以识别。JSON 对象和数组继续按 JSON 校验，错误 JSON 不会仅因包含分隔符而被当作卡密。
- **缺少认证信息的提示**：只有 accessToken、refreshToken 的 JSON 会明确提示补充认证方式。Google/GitHub 凭证需填写对应 provider；Builder ID/OIDC 凭证需补齐 clientId、clientSecret，企业账号还需明确填写 provider。增加空格或数组括号不会补齐这些字段。
- **连接恢复后再次切换**：DNS 解析失败、连接被拒绝等可确认刷新请求尚未发出的错误，现在显示为可重试的连接故障。恢复网络或代理后可再次切换或刷新，无需因这类错误重启管理器。请求可能已发出、响应丢失等结果不确定的情况继续要求重新授权或同步最新凭证。

本版包含 [1.10.1 的 CLI 同步修复](v1.10.1.md) 和此前的 IDE / Crew / CLI 客户端选择功能。本次修复通过合成凭证的离线解析、实际导入入口与刷新状态回归；未新增真实账户授权或桌面实机验收结论。

升级前备份完整账户数据目录并退出旧版管理器。不同安装目录或 ZIP 不会隔离管理器数据，请勿同时运行新旧版本。macOS 安装包未签名及公证；macOS/Linux 请手动升级。
