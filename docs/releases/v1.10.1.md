# Kiro Account Manager v1.10.1

修复 CLI 读取整秒访问凭证时可能误暂停同步的问题。官方 CLI 会把 UTC 有效期中的 `.000Z` 正常改写为 `Z`；现在只忽略小数秒末尾零的等价表示，实际到期时间、Token、身份或登记变化仍会触发冲突保护。

本版包含 [1.10.0 的全部客户端选择功能](v1.10.0.md)：每次默认 IDE，保留原 IDE 切号和退出登录；Windows 上可连接已核验的 Kiro CLI 3.1.0、Crew 0.12.0，并可停止同步。

升级后请检查已有 CLI 连接状态。若旧连接已经暂停，正常关闭 CLI 会话后重新选择该账号连接即可；管理器凭证不会被清除，原刷新设置保持。

新增连接只同步短期 accessToken，不下发管理器的 refreshToken 或客户端密钥，不更改原自动刷新设置。请保持管理器运行；该连接针对本机客户端，不代表远程 Gateway、WSL 或其他运行环境已经切号。macOS/Linux 的新增 CLI/Crew 连接仍未开放。

补丁通过真实 CLI 的整秒序列化复现、等价日期与真实变更的回归检查、类型检查和构建。真实账号模型验证仍限于已记录的 Windows Builder ID 场景；其他提供商的新增路径以格式与合成凭证回归为主。

升级前备份完整账户数据目录并退出旧版管理器；不同安装目录或 ZIP 不会隔离账户数据，请勿同时运行新旧版本。
