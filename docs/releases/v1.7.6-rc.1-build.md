## 构建修正与使用边界

干净构建曾因上游 `postinstall: electron-builder install-app-deps` 强制重编译 cbor-extract 失败；改为核验已有的 Node-API 预编译模块，保留依赖自己的安装脚本，随后 npm ci 与远程构建通过。Electron 包元数据校验和打包运行库下载分开处理，不能把开发运行库文件缺失误判为无法打包。

安装器未配置发布者代码签名。本地检查了 ZIP 的 CRC 与关键载荷哈希；公开附件以以上远程构建摘要为准，本地构建可能因时间戳等产生不同文件哈希。

本轮未启动 Electron、安装器或开发版，未修改生产 1.7.5、真实账户、共享缓存或系统协议。真实浏览器授权和协议归属仍需隔离实机验收；ZIP 不能提供运行时隔离。使用前遵循 [隔离规范](../development-rules.md)。
