# v1.8.6 · 额度、套餐分类与客户端同步修复

## 本次更新

- **单账号导出按邮箱命名**：完整 JSON、精简凭证 JSON、TXT、CSV 等文件导出默认使用账户邮箱及对应扩展名。批量导出仍使用日期命名，空邮箱和非法文件名自动处理。
- **充值包计入可用余额**：单个检测、后台检查、刷新及导入统一计算基础、试用、奖励和有效充值额度。账户卡片、列表、详情和首页显示充值包余额及到期日；已过期的包不计入可用额度，月度套餐重置不清除仍有效的充值包。
- **套餐分类统一**：PRO MAX、POWER、PRO+ 分别筛选和统计。修复单个检测后 PRO+ 被归入 PRO、后台更新后分类反复变化的问题。保留上游原始套餐名称、类型及实际数值额度，未知套餐独立标记。
- **同步当前模型和账户服务**：模型目录与默认额度查询使用当前 Kiro ControlPlane 请求格式，保留账户的区域、真实 profile 和认证类型。模型目录按账户及凭证隔离缓存，分页失败不返回不完整列表，也不追加未经账户确认的静态可用模型。
- **模型生命周期和能力**：停止将已退役的 Sonnet 4 作为兜底，明确提示退役模型请求。保留新模型 ID，展示服务返回的提供商、状态、推理和缓存能力，按对应 schema 发送推理参数。
- **切号凭证同步**：CLI 保存刷新后返回的新 refreshToken 和实际有效期；刷新失败不写入旧凭证。双端切换只刷新一次，IDE 与 CLI 写入同一代凭证，后续写入失败仍保留已经轮换的新凭证。
- **保留真实客户端登记期限**：IdC 缓存不再虚构 90 天有效期。导入和切号保留实际登记到期时间；缺失、已失效或临近失效时提示重新授权，切号在刷新前检查。

## 升级与验证范围

升级前备份账户资料并正常退出旧管理器。安装到其他目录或使用 ZIP 不会隔离管理器数据，不要同时运行新旧管理器或让多个客户端同时刷新同一账户。

各平台分别执行离线回归、类型检查、生产构建和包内容校验后发布。未完成各平台桌面操作、真实账户登录、凭证刷新或新版 CLI 数据库的全面实机验收；本版不更改尚未核实的 CLI 数据库格式，也不新增外部企业 IdP / API key 登录入口。

Kiro 隔离多开仍仅支持 Windows。macOS 安装包未配置 Apple 开发者签名及公证；Linux 系统代理自动检测和证书安装仍有发行版兼容限制。macOS / Linux 暂不提供自动更新。
