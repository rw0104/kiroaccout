# v1.8.10 · 安全修复与 Kiro 设置更新

本版修复代理认证边界、HTTPS 证书校验、远程图片下载和账户存储安全问题，并包含原始账号搜索、Memory / Workflows 设置及模型阶梯倍率展示。

## 安全修复

- HTTP / SOCKS 代理和注册连接验证上游证书及主机名。K-Proxy 使用限定于自身连接的可信 CA。
- 所有推理入口、模型列表、单账号选择及失败后的备用账号选择遵守 API Key 账号范围和分组限制；补齐 Gemini 和 Claude 非流式的 Key 用量记录。
- HTTP `/admin` 管理接口关闭，普通推理 Key 不再获得管理权限；管理操作使用桌面应用。
- 远程图片仅允许公网 HTTP(S) 地址，连接固定到已验证的 IP；重新检查重定向，并限制响应头、下载大小和超时。
- Steering 文件操作限定于安全目录内的普通 `.md` 文件，并核验调用窗口和主 frame。
- 账户和应用配置改为 AES-256-GCM 加密，随机密钥由系统安全存储保护。旧库经校验后自动迁移，并保留加密迁移归档和上一代备份。
- 日志不再输出验证码、设备授权码和邮箱；控制台与历史日志在输出前统一脱敏。
- 升级 Electron、Undici、更新器和 TLS 依赖。证书生成改用 Node WebCrypto 与新的 X.509 库，保留已有 CA 和私钥的兼容性。

## 功能更新

- 搜索支持邮箱、别名和原始导入账号名；旧账号可手动补充原始名称，导出和恢复会保留。
- Kiro 设置可选择默认 IDE 或受管实例，配置 Memory 四档和 Workflows 总开关。会话使用频率仍在官方聊天面板调整。
- JSONC 保存保留注释、URL、尾逗号及未知设置，只提交修改字段。
- 修复快速切换实例时旧模型结果覆盖新结果，以及 MCP / Steering 操作后丢失未保存设置的问题。
- 模型卡片显示已核对的上下文阶梯倍率及官方来源；目录倍率变化时优先展示服务返回值。

## 升级说明

升级前导出并妥善保存账户备份，退出旧管理器后安装。新库由原系统用户的安全存储保护，旧版管理器不能直接读取；跨机器迁移请使用明确包含凭证的导出文件。不要同时运行新旧管理器。

Linux 需要可用的 Secret Service 或 KWallet，macOS 需要解锁钥匙串。安全存储不可用时会停止启动并保留原文件，不回退到明文存储。

使用自签代理证书的客户端需要信任对应 CA，并保持证书验证开启。依赖 HTTP `/admin` 的外部脚本需要改用桌面管理功能。

## 验证

- 633 项离线单元和集成回归通过，类型检查和生产构建通过。
- HTTPS / SOCKS 证书、DNS 地址与重定向、Key 范围、额度记录、路径与链接、敏感日志、旧库迁移和中断恢复均有合成数据回归。
- 全量及生产依赖审计均未报告已知漏洞。
- 不安装到现有生产目录，不使用真实账户执行认证或 Token 刷新。此前 Haiku 5.5 的目录、短请求和长上下文验证不代表本版全部模型或所有登录方式的真实验收。

Windows x64、macOS Intel / Apple Silicon、Linux x64 的实际附件与 SHA-256 校验文件以本次 Release 为准。macOS 安装包未签名及公证；macOS / Linux 仍采用手动升级。
