# v1.7.6 · Windows x64

## 本次更新

- 软件内更新：启动后检查正式版本，提供下载进度与重试；下载校验完成后，由用户确认重启安装。安装前保存账户资料，保存失败时不退出；不在普通退出时静默安装更新。
- 若安装器异步启动失败，阻止更新器已排定的退出，并提示重启应用后重试或手动下载安装包。
- 更新源、源码及问题反馈入口统一指向 `rw0104/kiroaccout`。正式更新通道不向用户推送 RC 或旧版本。
- README 改为用户操作说明；当前公开文档移除本机工作区、私人用户名、原始样例名及运行进程信息。
- 关于页面移除原作者的 QQ 群、二维码、个人头像和捐赠入口，清除相应分发资源。开源许可证及必要归属保留在随包声明中。
- 延续 JSON/OIDC 导入兼容、备份恢复和登录会话修复。

## 下载

- `kiro-account-manager-1.7.6-x64-setup.exe`：Windows x64 安装包。
- `kiro-account-manager-1.7.6-x64-windows.zip`：解压运行目录。
- `kiro-account-manager-1.7.6-x64-setup.exe.blockmap`、`latest.yml`：软件更新需要的差分信息和通道清单。
- `SHA256SUMS.txt`：上述附件的 SHA-256 校验值。

软件内更新适用于本仓库构建的版本。原作者的 1.7.5 仍使用其原更新源，首次切换需先备份资料并手动安装本仓库版本；本次发布不会主动改动运行中的旧客户端。

## 验证范围

发布流程检查离线回归、类型、源码构建、包内容、更新清单与实际安装器的版本/大小/SHA-512，并在上传后复核附件摘要。自动更新的状态、下载失败、重试及保存确认通过 mock 更新器测试；未在用户生产客户端上执行真实升级。安装包未配置发布者代码签名。

正式版表示稳定通道分发，不代表尚未执行的浏览器授权或安装回退实机检查已经完成。已有重要资料时请先备份，再在独立环境验证；ZIP 同样不提供账户或协议隔离。

**Kiro 客户端隔离多开与 JSON 导出进一步完善仅列入后续需求，本版不包含这两项新增实现。**
