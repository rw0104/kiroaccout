# Kiro Account Manager v1.8.13

修复部分用户升级后，因旧版账户资料再次变化而出现“账户安全存储不可用”、无法打开管理器的问题。

## 修复内容

- 新增启动恢复窗口。现有安全库可以读取时，可选择“备份并使用现有安全库”，保全新旧资料后继续启动。
- 保留冲突旧文件、原始迁移归档和恢复资料；主库损坏但备份可用时，也会在恢复前保全损坏主库的原始内容。
- 普通备份保存会保全来自旧版或其他来源的未知备份，避免静默覆盖尚未核对的资料。
- 已确认的同一批旧资料无需在每次启动时重复确认；资料再次变化时重新提示。本版正常保存和备份不会反复触发恢复窗口。
- 恢复确认前不启动账户刷新、同步或代理。取消恢复时保留资料并退出；备份或校验失败时不会继续启动后台操作。
- 保留原始账号名搜索、补充名称及导入导出功能。

## 升级说明

安装前退出旧版管理器，备份整个账户数据目录，不要同时运行新旧版本。

出现恢复窗口时，“备份并使用现有安全库”会使用当前安全库启动，**不会自动合并旧文件中的新增账户或更新凭证**。启动恢复后仍需核对保留的旧资料是否有遗漏。

请保留原系统用户、完整数据目录及密钥文件，不要删除账户目录或密钥来绕过提示。密钥缺失、系统安全存储不可用或主备库均无法解密时，仍需先恢复有效备份。
