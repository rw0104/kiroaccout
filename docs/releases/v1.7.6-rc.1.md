# v1.7.6-rc.1 · Windows x64 预发布

本版本修复账户 JSON/OIDC 导入及网页登录的本地会话和回调处理。发布为候选版本，**真实 Windows 浏览器授权、系统协议归属和当前 Kiro Social 精确契约尚未完成隔离实机验收**。

## 主要改动

- 文件导入、设置页和 OIDC 批量输入共用解析规则，支持账户数组、对象、包装、嵌套凭证与字段别名。
- 修正 `Builder ID` 被误判为 Social；完善备份恢复、ID 冲突保护、去重、结果计数和保存确认。
- 登录操作绑定会话；取消及旧响应不会清空新登录。Social 回调缓存，Builder 串行轮询并处理 slow_down，IAM 使用动态 loopback 端口。
- 更新源改为本仓库，版本比较支持 RC；打包使用明确的应用文件白名单。
- 新增开发文档、离线回归及可重复的 Windows 构建/校验脚本。

## 下载与验证

- `kiro-account-manager-1.7.6-rc.1-x64-setup.exe`：Windows x64 安装器。
- `kiro-account-manager-1.7.6-rc.1-x64-windows.zip`：解压运行目录；它不提供独立数据或协议隔离。
- `SHA256SUMS.txt`：以上两个文件的 SHA-256。

在 PowerShell 使用 `Get-FileHash -Algorithm SHA256` 核对下载文件与校验清单。本版本未配置发布者代码签名，Windows 可能显示发布者验证提示。源码和 AGPL 许可证保留于仓库及安装目录。

## 验证与使用边界

本轮 90 项离线回归与 TypeScript/Vite 构建通过；发布前还检查包内容。未运行安装器或通过生产账户测试真实认证，本次构建和发布未读取或导入生产账户。本版本不具备运行时沙箱。

**已有 1.7.5 正在使用时，请在独立 OS 用户或虚拟机中使用本候选版本和独立测试账户。** 普通安装或 ZIP 启动仍可能共享用户数据、AWS/CLI 缓存及 `kiro://` 协议；不要在同一用户会话中直接双开进行测试。

本次不提供稳定自动更新通道元数据，不将该 RC 标记为 latest。实际新增账户仍取决于网络与上游凭证有效性。

开发、构建及隔离流程见 [开发文档](https://github.com/rw0104/kiroaccout/blob/main/docs/DEVELOPMENT.md)。
