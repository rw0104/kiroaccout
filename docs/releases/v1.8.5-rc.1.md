# v1.8.5-rc.1 · Windows / macOS / Linux Preview

本次预览版增加 macOS 和 Linux 下载包，保留 1.8.4 的账户管理及恢复记录修复。它不替代当前 Windows 正式版，不通过正式更新通道推送，请从本页手动下载。

## 下载选择

| 系统 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64 | `kiro-account-manager-1.8.5-rc.1-x64-setup.exe` / `kiro-account-manager-1.8.5-rc.1-x64-windows.zip` |
| macOS Intel | x64 | `kiro-account-manager-1.8.5-rc.1-x64-mac.dmg` / `kiro-account-manager-1.8.5-rc.1-x64-mac.zip` |

| Linux | x64 | `kiro-account-manager-1.8.5-rc.1-x64-linux.AppImage` / `kiro-account-manager-1.8.5-rc.1-x64-linux.deb` |

`SHA256SUMS.txt` 提供全部安装包的 SHA-256 校验值。Linux AppImage 下载后需赋予执行权限；DEB 适用于 Debian / Ubuntu 系列。

## 调整

- Kiro 设置读取和保存使用对应系统的配置目录；Windows 使用 APPDATA，macOS 使用 Library/Application Support，Linux 支持 XDG_CONFIG_HOME。
- 各平台打包对应架构的原生依赖及 TLS 动态库，减少首次使用时额外下载的依赖。
- 每个平台分别执行离线回归、类型检查、生产构建及安装包内容校验，全部完成后统一发布。

## 使用范围

- **Kiro 隔离多开仍仅支持 Windows。** macOS / Linux 不提供此功能。
- macOS 安装包未配置 Apple 开发者签名及公证，系统可能阻止首次打开；请在确认下载来源后通过系统的“隐私与安全性”检查相关提示。
- Linux 暂不提供系统代理自动检测，请手动配置代理；系统证书安装尚未完成发行版兼容验收。
- 本版未完成 macOS / Linux 桌面操作、真实账户登录、凭证刷新、账户切换或安装验收。构建和离线检查通过不代表这些操作已实机验证。
- 本次预览版请手动下载和升级，不承诺 macOS / Linux 自动更新可用。

升级前备份账户资料，正常退出旧管理器。安装到其他目录或解压 ZIP 不会隔离管理器数据，不要同时运行新旧管理器。不要让同一账户由多个客户端同时刷新凭证。
