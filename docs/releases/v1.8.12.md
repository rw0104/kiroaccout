# Kiro Account Manager v1.8.12

- 修复部分旧版导入账户点击启动/切换时，因缺少 OIDC 登记有效期而被直接拦截的问题：从对应客户端凭证恢复原始截止时间，并在正常刷新验证成功后交给 Kiro IDE。
- 区分“登记信息无法恢复”和“登记确实过期”的提示；保留过期保护，不延长或虚构有效期。
- 修复关闭窗口时出现 `Object has been destroyed` 错误弹窗的问题。
- 修复 Windows 应用内更新安装完成后未自动启动管理器的问题；确认安装更新后，将自动完成安装并启动新版。
- 手动安装保留安装向导，完成页默认勾选运行管理器，可按需取消。
