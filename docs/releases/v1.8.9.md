# v1.8.9 · Kiro 设置、模型倍率与原账号搜索

本版补齐 Kiro 1.4.26 的设置入口，并修复设置保存和实例切换中的数据覆盖问题。

## 更新内容

- “Kiro 设置”可选择默认 IDE 或 Windows 受管实例，读写和打开文件均作用于所选配置。实例的模型目录来自其绑定账号。
- 新增 Memory 四档与 Workflows 总开关；默认关闭，保留已有选择。工作流使用频率仍在官方会话面板设置。
- 使用 JSONC 解析与局部编辑，保留注释、URL、尾逗号和其他设置。只保存改动字段，无效文件不会被覆盖。
- 修复快速切换配置时旧模型目录覆盖新结果，以及 MCP / Steering 操作完成后清除未保存设置的问题。
- 模型卡片显示已核对的短／长上下文倍率与官方来源。服务目录数值与文档不符时优先显示目录数值，不沿用过时阶梯。
- 搜索支持原始导入账号名，真实邮箱显示逻辑保持不变；支持导入补充、手动编辑、导出和恢复。
- 集中维护既有服务请求标识，避免把 IDE 版本号更新误当作协议更改。

## 验证范围

557 项离线回归、类型检查和生产构建通过。真实账户的模型目录、额度查询、Haiku 5.5 短请求及长上下文请求通过；长请求服务报告上下文占用约 85.65%。这不等于验证了全部模型或每种账号登录方式。

设置和倍率界面使用真实组件及合成 IPC 在浏览器中验证，不修改日常 IDE 的配置。未执行双账号登录或 Token 轮换测试。

## 安装

Windows x64 产物：`kiro-account-manager-1.8.9-x64-setup.exe` 与 `kiro-account-manager-1.8.9-x64-windows.zip`。使用对应 SHA-256 校验文件核对下载。

升级前备份账户资料并退出旧管理器。ZIP 或不同安装目录不会隔离管理器数据，不要同时运行新旧版本。公开发布状态与其他平台附件以 Releases 实际内容为准。
