# Kiro Account Manager v1.10.8-rc.1

本预发布版改进 macOS 安装包的签名与发布校验，供需要手动允许打开的用户使用。账户功能沿用 v1.10.7。

- macOS 安装包使用临时签名（ad-hoc），并启用强化运行时及 Electron 所需权限。
- 许可证和第三方声明放入 macOS 应用的 Resources 目录，避免签名时被当作嵌套代码。
- 发布前校验整个应用的签名完整性，同时保留原生 TLS 库的来源及 SHA256 校验。
- 提供 Apple Silicon（arm64）和 Intel（x64）的 DMG / ZIP，以及对应 SHA256 校验文件。macOS 需要 13 或更高版本。

**此版本没有 Developer ID 身份签名，也未经 Apple 公证。临时签名完整性通过不代表 Gatekeeper 信任，首次打开仍可能被系统拦截。** 这是预发布版，不会成为正式版自动更新目标。

## macOS 安装及首次打开

1. 在“关于本机”确认芯片类型：Apple 芯片选择 `arm64-mac.dmg`，Intel 选择 `x64-mac.dmg`。
2. 下载本 Release 中对应的 DMG 和 `SHA256SUMS-darwin-arm64.txt` 或 `SHA256SUMS-darwin-x64.txt`。在下载目录执行 `shasum -a 256 <DMG文件名>`，与校验文件中该 DMG 的一行比较；不一致时重新下载。
3. 退出旧管理器，备份原有资料，打开 DMG，把 **Kiro Account Manager** 拖到“应用程序”。同一用户的新旧版本共享应用数据，请勿同时运行。
4. 尝试打开一次，然后到“系统设置 → 隐私与安全性”找到该应用，点击“仍要打开”。参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

如果仍提示“已损坏”，且已确认下载来自本仓库、SHA256 相符，可以在终端对这个应用单独执行：

```bash
codesign --verify --deep --strict "/Applications/Kiro Account Manager.app" &&
xattr -dr com.apple.quarantine "/Applications/Kiro Account Manager.app"
```

这条命令先校验应用签名，成功后只移除该应用的下载隔离标记；它不会让应用获得 Apple 公证。若签名校验报错，请重新下载，不要继续处理该副本。随后从“应用程序”打开管理器。安装在其他目录时，请把两处路径改成实际应用路径。

验证范围为离线回归、类型检查、编译、安装包内容及签名完整性；未完成真实账户登录、刷新或桌面操作验收。macOS / Linux 请手动升级；多开及原生 CLI / Crew 连接仍以现有平台支持范围为准。
