# Kiro Account Manager v1.10.4

修复长期运行后的账号凭证不同步、临时错误恢复，以及账号切换和后台保存的性能问题。

- **后台续期同步**：管理器成功刷新账号后立即向运行中的代理账号池同步凭证，避免池内继续使用已失效的旧刷新凭证；新凭证不会清除真实封禁和额度限制。
- **临时错误恢复**：明确的临时刷新故障使用退避重试，不因访问凭证在故障期间到期而永久停用账号。真实认证拒绝仍需要重新授权；结果不确定的刷新和已经开始的生成请求不会自动重放。
- **错误分类**：短时 429 限流与 402 额度耗尽分别处理，避免将限流误记为长时间额度耗尽并随后显示本地 503。错误文本中的普通三位数字不再当成 HTTP 状态码。
- **账号切换**：持久化的当前账号凭证健康且有效期充足时直接交接，减少不必要的网络刷新。临近到期、到期时间不明或状态异常的账号仍执行必要校验与刷新。
- **后台保存与列表**：合并并发的全量保存请求，减少账号较多时重复序列化、IPC 和磁盘写入；列表按实际使用的状态订阅，减少后台状态变化引发的重复渲染。
- **内存与连接资源**：网络代理连接池按地址与信任配置复用，限制缓存数量并回收空闲池；诊断请求释放响应与专用连接池。Token 估算仅在首次使用时载入所需的 cl100k 编码表。
- **客户端兼容**：核对官方 Kiro IDE 1.4.154 / Agent 1.1.873 的认证、Runtime 和 Management 请求，更新 Social 刷新的专用 User-Agent。其它适配器保持各自已验证的协议身份。

本次通过合成账号、受控时钟及本地网络回归验证上述行为，并执行类型检查与生产构建。没有将这些结果扩大为所有真实账号、多小时桌面运行或全部上游错误均已现场验收的保证。

升级前备份账户数据并退出旧版管理器。不同安装目录或 ZIP 不会隔离管理器自身的数据，请勿同时运行新旧版本。
