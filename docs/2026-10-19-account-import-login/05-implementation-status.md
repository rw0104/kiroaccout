## 2. 已实现的导入修复

- 共享 `accountImport`、`authIdentity` 及 `backupRestore` 模块已接入账户管理文件导入、设置 JSON 导入与 OIDC 批量输入。支持明确的对象/数组/包装结构、嵌套 credentials、字段别名、BOM、完整代码围栏及现有文本语法。
- Builder ID 展示别名归一为 BuilderId/IdC；Google/GitHub 别名统一为 Social 身份。显式未知渠道、身份冲突、错误字段类型和不完整 OIDC 三件套给出逐条错误，不默认当 Social。
- 批量预览、按钮数量与提交使用同一个计划。完整备份与简化凭证分别处理，无 Token 的完整备份仍可恢复元数据，并标记 unknown。
- 备份恢复保护本地账户 ID、分组和标签定义，处理 ID 碰撞及引用重映射；不完整账户不能靠备份头包装入库。
- 新增、重复、无效、失败和取消分别计数；批量结果保留供核对，不直接关闭清掉结果。
- 跨导入入口共用串行队列；当前会话记录已消费原始 Token 与新增账户的关联，防止重复输入再次兑换旧 Token。保存失败后可只重试保存，避免重复刷新。
- 关键操作等待持久化确认；修复在途保存期间新快照被误认为已保存的问题。失败保留内存账户并明确提示，不计为持久新增成功。

这些兼容规则不意味着任意合法 JSON 都是可导入账户。缺少渠道且不能由完整 OIDC 凭证确定身份时，需用户补全；空账户备份不在本轮扩展范围。

## 3. 已实现的本地认证修复

先完成 [当前认证取证](04-current-auth-evidence.md)，再修本地交接；保留现有请求端点、header/body、scope 与 redirect，未猜测迁移未公开验证的 Social 契约。

- 主进程 `LoginSessionManager` 统一绑定 sessionId、provider、state、PKCE、取消信号、有效期与回调服务。启动、轮询、兑换及取消都检查会话归属，旧异步结果不能清空新会话。
- Builder 设备授权同时限制最小轮询间隔与单次在途请求；前端串行调度并消费 slow_down。设备响应重新设置真实有效期，不让注册耗时吃掉授权窗口。
- Google/GitHub 回调先在主进程缓存；界面先订阅后启动，并可主动查询缓存。错误 state 不销毁有效会话，重复回调不重复兑换。超时明确退出等待，定时器和迟到回调共用一次性过期处理。
- IAM 使用同一个 server 绑定 127.0.0.1 动态端口，监听就绪后才返回授权 URL；旧回调结果不能进入新会话。畸形请求返回 400，不产生未处理 Promise rejection。
- 关闭对话框、取消、切换及重试会立即使旧界面会话失效，迟到的凭证验证结果不能添加账户。
- 在线登录成功后先验证、添加并确认保存，再关闭界面；保存失败有单独重试入口，不重新兑换授权码。
- 相关错误使用固定提示或受控分类；新增代码不将原始授权码、Token、邮箱或上游响应写入日志。相关刷新日志也去掉客户端凭证前缀和原始错误 body。
