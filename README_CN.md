# kiroaccout

Kiro 账户管理桌面应用，用于管理账户、分组和标签，导入、导出 JSON，并查看账户状态。

[正式版下载](https://github.com/rw0104/kiroaccout/releases/latest) · [全部版本](https://github.com/rw0104/kiroaccout/releases) · [源码与问题反馈](https://github.com/rw0104/kiroaccout) · [开发文档](docs/DEVELOPMENT.md)

当前源码目标为 **1.8.0 · Windows x64**，发布状态及附件以 Releases 为准。升级前先备份原有资料。安装到其他目录或使用 ZIP 不会隔离账户管理器自身的数据，不要同时运行新旧管理器。

## 使用

- 网页登录：打开“添加账户 → 在线登录 → 打开 Kiro 网页登录”。Google、GitHub 快捷入口也使用门户和本地 HTTP 回调，不抢占官方 IDE 的 `kiro://` 协议。
- 导入 JSON：在“账户管理”导入文件，或在“添加账户 → OIDC 凭证 → 批量”粘贴凭证。
- 导出 JSON：在“账户管理”或“设置 → 数据管理 → 导出”选择全部/选中账户、完整备份 JSON 或精简凭证 JSON。**默认不含登录凭证，只能恢复账户资料；要迁移登录信息，必须明确勾选“包含登录凭证”。** 含凭证文件为明文，请妥善保管。
- Kiro 客户端多开：进入“Kiro 隔离多开”，选择一份官方 `Kiro.exe`、实例名称和管理器内已有账户，创建后启动。启动时将所选账户的凭证写入该实例的专用缓存，无需重复安装、创建 Windows 用户或重新登录；访问凭证过期可由实例续期，刷新凭证或 IdC 客户端登记失效需重新授权。
- 实例管理：查看运行状态，正常停止或重启指定实例。未保存编辑可能阻止关闭，不会自动强杀。移除配置保留实例文件；旧 RC 的 Windows 用户配置需移除后重建。
- 检查正式更新：打开“关于 → 检查更新”，按提示下载并确认安装。

绑定期间该实例独占所选账户的刷新，管理器拒绝对该账户再次刷新、切号或绑定另一实例。启动前只读比较默认 IDE 的凭证，发现共用时拒绝启动，不复制或改写其缓存。移除绑定前须停止实例并同步最新凭证；实例中改登其他账户时，不会盲目覆盖原账户。实例分别保存配置、登录缓存、扩展和临时文件；系统网络、代理、证书、Windows 身份和 DPAPI 仍共享，这不是安全沙箱。不要在旧管理器或其他客户端同时刷新同一账户。

若缓存丢失、过期或改登导致无法同步，可在停止实例后选择“恢复解绑”并确认。全部实例文件保留，原账户需重新授权，未核验凭证不会回写。
