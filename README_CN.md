# kiroaccout

Kiro 账户管理桌面应用，用于管理账户、分组和标签，导入、导出 JSON，并查看账户状态。

[正式版下载](https://github.com/rw0104/kiroaccout/releases/latest) · [全部版本](https://github.com/rw0104/kiroaccout/releases) · [源码与问题反馈](https://github.com/rw0104/kiroaccout)

当前源码目标为 **1.8.18 · Windows / macOS / Linux**，发布状态及附件以 Releases 为准。macOS / Linux 请手动下载安装和升级。升级前先备份原有资料。安装到其他目录或使用 ZIP 不会隔离账户管理器自身的数据，不要同时运行新旧管理器。

账户迁移恢复：升级后若发现变化的旧版资料，可在恢复窗口选择“备份并使用现有安全库”。新旧资料会保留，旧文件中的新增账户或凭证不会自动合并；请保留整个数据目录与密钥供后续核对。

安全更新：代理 HTTPS 校验证书，远程图片仅允许公网地址，推理 Key 不再具有 HTTP 管理权限。账户数据首次启动时自动迁移到系统密钥保护的加密库；请先解锁系统钥匙串。跨机器迁移使用显式包含凭证的导出，旧版不能直接读取新库。

## 使用

- 网页登录：打开“添加账户 → 在线登录 → 打开 Kiro 网页登录”。Google、GitHub 快捷入口也使用门户和本地 HTTP 回调，不抢占官方 IDE 的 `kiro://` 协议。
- 导入 JSON：在“账户管理”导入文件，或在“添加账户 → OIDC 凭证 → 批量”粘贴凭证。
- 导出 JSON：在“账户管理”或“设置 → 数据管理 → 导出”选择全部/选中账户、完整备份 JSON 或精简凭证 JSON。**默认不含登录凭证，只能恢复账户资料；要迁移登录信息，必须明确勾选“包含登录凭证”。** 含凭证文件为明文，请妥善保管。
- 搜索支持邮箱、别名和原始导入账号名；旧账号可在“编辑账号 → 原始账号”中补充。
- Kiro 设置：选择默认 IDE 或受管实例，配置 Memory 和 Workflows；会话使用频率在官方聊天面板中调整。
- 工具自动批准：在“Kiro 设置 → 工具自动批准”中检查所选默认 IDE 或受管实例，主动点击“应用自动批准配置”后才写入；应用前备份，可在文件未被外部修改时恢复原配置。仅有 `permissions.json` 时保持只读，可导出 YAML 模板自行迁移。自动批准允许执行命令和修改文件，已有限制及内置保护仍可能要求确认；建议新建 Kiro 会话验证。
- 模型卡片显示已核对的上下文阶梯倍率；目录数值变化时优先显示服务返回值。
- 单账号导出默认使用邮箱作为文件名；批量导出保留日期命名。
- 额度显示包含基础、试用、奖励及有效充值包，充值包单独显示余额和到期日。
- 套餐筛选支持 PRO MAX、POWER 和未知类型；已有账户加载时统一分类，不改变原始套餐标题。
- Kiro 客户端多开（仅 Windows）：进入“Kiro 隔离多开”，选择一份官方 `Kiro.exe`、实例名称和管理器内已有账户，创建后启动。启动前将所选账户的凭证复制到该实例的专用缓存，无需重复安装或创建 Windows 用户；访问凭证过期可由实例续期，刷新凭证或 IdC 客户端登记失效需重新授权。
- 实例管理：查看运行状态，正常停止或重启指定实例。未保存编辑可能阻止关闭，不会自动强杀。移除配置保留实例文件；旧 RC 的 Windows 用户配置需移除后重建。
- 后台运行：隐藏窗口会暂停日志界面刷新和装饰动画，代理与账户后台任务继续；日志保留有容量限制的近期记录，超长字段会标注截断。
- 检查正式更新：打开“关于 → 检查更新”，按提示下载并确认安装。

创建配置仅记录账户选择；启动准备失败且确认未启动客户端时，原账户仍可在管理器使用，配置可直接移除。启动交接后，该实例独占所选账户的刷新，管理器拒绝对该账户再次刷新、切号或绑定另一实例。复制缓存不会改写原账户的登录方式、提供商或 profile；核验后的凭据变化只同步 Token 和到期时间。启动前只读比较默认 IDE 的凭证，发现共用时拒绝启动，不复制或改写其缓存。移除绑定前须停止实例并同步最新凭证；实例中改登其他账户时，不会盲目覆盖原账户。实例分别保存配置、登录缓存、扩展和临时文件；系统网络、代理、证书、Windows 身份和 DPAPI 仍共享，这不是安全沙箱。不要在旧管理器或其他客户端同时刷新同一账户。

若缓存丢失、过期或改登导致无法同步，可在停止实例后选择“恢复解绑”并确认。全部实例文件保留，原账户需重新授权，未核验凭证不会回写。
